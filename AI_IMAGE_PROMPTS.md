## 📐 出力仕様・使用方法

### サイズ
| 用途 | サイズ | 備考 |
|------|--------|------|
| キャラ選択画面 | 256×256 px | 円形クロップ |
| 対局画面バッジ | 64×64 px | 縮小版 |
| ストーリー演出 | 512×512 px | フル表示 |
| カスタマイズ画面 | 128×128 px | グリッド表示 |

### Flutterへの組み込み
```dart
// assets/images/characters/{character_id}.png として配置
// pubspec.yaml に追加:
// assets:
//   - assets/images/characters/

Image.asset(
  'assets/images/characters/${character.id}.png',
  width: 64,
  height: 64,
)
```

### Leonardo AI 推奨設定
```
Model      : Leonardo Anime XL
Preset     : Anime
Guidance   : 7
Steps      : 30
Seed       : 固定（同じキャラの複数バリエーション生成時）
```

### Canva AI 推奨設定
```
スタイル   : アニメ / イラスト
縦横比     : 1:1
詳細度     : 高
```
