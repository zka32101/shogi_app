# iOS Image Specifications

## App Icon
Size: 1024 x 1024 pixels
Format: PNG
Purpose: App Store icon

## Screenshots (5-10 required)
Size: 1170 x 2532 pixels (iPhone 13)
Format: PNG, JPG
Content: Show app features
Text: Include feature captions

Duration: 15-30 seconds
Dimensions: Same as screenshots
Format: MOV
