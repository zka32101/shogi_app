# Android Image Specifications

## Feature Graphic
Size: 1024 x 500 pixels
Format: PNG, JPG
Purpose: Store listing hero section
Content: App logo + key feature

## Icon
Size: 512 x 512 pixels
Format: PNG
Purpose: App store icon

## Screenshots (5 minimum)
Size: 1080 x 1920 pixels (9:16 ratio)
Format: PNG, JPG
Content: Show 5 key features
Text: Include feature descriptions
