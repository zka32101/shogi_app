│   - GameScreen + GameSettings + _BoardWidget
│   - 9x9 interactive board display
│   - Piece selection & move visualization

│   - Move history (kifu) in Japanese notation
│   - Timer display (if enabled)
│   - Undo functionality
│   - Checkmate detection
│
├── editor_screen.dart (~450 lines)
│   - EditorScreen + _PieceSelector
│   - Place pieces on board (both players)
│   - Edit hand pieces (captured)
│   - Load standard position
│   - Load empty board
│   - Launch game from edited position
│
├── tsume_screen.dart (~400 lines)
│   - TsumeScreen + _BoardDisplay
│   - Display puzzle board & hand pieces
│   - Restrict input to attacking player
│   - Validate moves legally
│   - Detect checkmate
│   - Show success/failure
│

│   - PieceType enum (14 types)
│   - Piece class (type, owner, label, promotion logic)
│   - AMove class (AI move representation)
│   - KifuMove class (move notation in Japanese)
│   - TsumeProblem class (puzzle data)
│   - tsumeProblems list (5 built-in puzzles)
│
└── logic.dart (~400 lines)
    - Move validation (piece-specific rules)
    - AI engine (minimax, configurable depth)
    - Piece attack calculation
    - Check/checkmate detection
    - Board state management
